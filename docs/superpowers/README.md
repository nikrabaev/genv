# Design specs & plans (historical)

These are the design specs and implementation plans from the **menv** monorepo
era, imported verbatim when the Go implementation was extracted into this
repository and rebranded to **genv**. They are kept as the historical design
record.

"menv" throughout these documents refers to the same tool that is now genv; the
on-disk names (`menv.json`, `.menv/`, `menv-local`, `MENV_*`) are the pre-rebrand
equivalents of today's `genv.json`, `.genv/`, `genv-local`, `GENV_*`.
